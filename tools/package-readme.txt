Aquarium for Squeak
===================

A small Smalltalk game: two fish swim around the screen, and you steer them
from the control panel: Grow, Diet, <<-- and -->> (turn), Flip, Move, Stop,
one row for each fish. The blue fish also answers the keyboard: j turns it
left, k flips it, l turns it right. Quit with the Quit button.

START: see below for your system. Squeak 6.0, which runs it, is included.

The game is Aquarium.image, a Squeak 6.0 image with the Aquarium in it: open
any class with the browser (Tools menu) to read its code, Fish and
ControlPanel, and change it while it runs.

Source, more about it, and the other systems:
https://github.com/edragoev1/aquarium-for-squeak
